# Medico frontend

React 18 + Redux Toolkit + React Router + Bootstrap, built with [Vite](https://vite.dev).

Requires Node.js 20.19+ or 22.12+.

## Scripts

| Command | What it does |
|---------|--------------|
| `npm run dev` / `npm start` | Start the Vite dev server on http://localhost:3000 |
| `npm run build` | Production build into `build/` |
| `npm run preview` | Serve the production build locally |

Yarn works too (`yarn dev`, `yarn build`); both `package-lock.json` and `yarn.lock` are kept in sync.

The app expects the Spring Boot backend (`Medico/`) on http://localhost:8080.
